## Build and Test Instructions

This project targets Java 21 and requires no pre-installed build tools when using the provided Maven Wrapper.

### Compile the project:
- **macOS / Linux**: `./mvnw compile`
- **Windows**: `mvnw.cmd compile`

### Run all tests:
- **macOS / Linux**: `./mvnw test`
- **Windows**: `mvnw.cmd test`

## Repository Structure
- `src/main/java`: Domain models, service interfaces, and business logic implementations.
- `src/test/java`: Invariant test suites and adversarial test cases.
- `docs/`: Design documentation and AI usage records.
